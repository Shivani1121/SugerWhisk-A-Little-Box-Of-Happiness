# 🍰 Sugarwhisk — Bakery & Chocolate E-Commerce Website

Sugarwhisk is a cute, playful, and visually appealing bakery and chocolate e-commerce website designed with a soft pastel pink and cream aesthetic. It brings together a delightful collection of sweet treats, including cakes, chocolates, cookies, macarons, candies, and gift boxes, in one charming online shopping experience.

## ✨ Features

- 🎂 **Product Collection:** Browse a variety of bakery items, chocolates, cookies, candies, and gift boxes.
- 🔍 **Search & Filters:** Find products easily using the search bar and category filters.
- 🛍️ **Shopping Cart:** Add products to your cart and manage your selections.
- 💕 **Wishlist:** Save your favorite sweet treats.
- 🎁 **Custom Gift Box Builder:** Create personalized gift boxes for special occasions.
- 🏷️ **Coupon Feature:** Try the demo discount code `SWEET10`.
- 📱 **Responsive Design:** Enjoy a user-friendly layout across desktop and mobile screens.
- 💌 **Newsletter Interface:** Explore the newsletter signup experience.
- 🎨 **Pastel Theme:** A soft pink and cream design with a cute, bakery-inspired visual identity.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Project Objective

The goal of Sugarwhisk is to create an attractive and interactive front-end e-commerce experience while practicing web development fundamentals, responsive design, DOM manipulation, event handling, and basic shopping cart functionality.

## 🚀 Future Improvements

- Java backend integration

## 👩‍💻 Project Status

This is a front-end demonstration project. Checkout, coupon, and newsletter interactions are demo features; real payments and backend order processing are not yet implemented.
